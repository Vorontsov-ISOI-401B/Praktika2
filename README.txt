Инициализируем файл, где будем работать с помощью команды git init
1) Вводим в терминале Git Bush следующее:
git clone (твоя ссылка из GitHud, и скобки убираем)
2) переходим в папку проекта командой cd
3) Создаем виртуальную среду командой python -m venv venv
4) активируем виртуальную среду командой source venv/Scripts/activate (для windows)
source venv/bin/activate (для linux или macOS)
5) Устанавливаем все зависимости, они уже есть в папке requirements.txt, его просто нужно установать через терминал:
pip install -r requirements.txt
Все готово, остался только запустить сервер, введя команду:
uvicorn api:app --port 8000 --reload
Затем зайди в любой браузер и зайти в созданный адрес, который будет на строчке с началом INFO:  ...
